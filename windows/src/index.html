Connect an iPhone

Windows needs Apple's driver to see the iPhone. If the phone doesn't appear, install the Apple Devices app (or iTunes) from the Microsoft Store, then plug the phone in and unlock it.

  1. 1 · Trust this computer
    Unlock the iPhone. When it asks "Trust This Computer?", tap Trust and enter the passcode.
  2. 2 · Turn on Developer Mode
    Click, then on the iPhone: Settings → Privacy & Security → Developer Mode → on, and restart. After it restarts, unlock and tap Turn On.
  3. 3 · Prepare the iPhone
    Installs Apple's developer image. Needs internet. Repeat after the iPhone restarts.
